# PLACE TRAFFIC 런처

네이버 플레이스 트래픽 프로그램 런처입니다.

## 다운로드

아래 **세 개를 모두 받아 한 폴더에 넣어** 주세요.

| | 파일 | 설명 |
|---|---|---|
| 1 | **[⬇ PlaceLauncherV10.exe](https://github.com/hihiood/place-launcher/releases/latest/download/PlaceLauncherV10.exe)** | 프로그램 (267MB) |
| 2 | **[⬇ secret.xlsx 양식](https://github.com/hihiood/place-launcher/raw/main/docs/secret_%ED%85%9C%ED%94%8C%EB%A6%BF.xlsx)** | 매장·검색어를 적는 엑셀. 받아서 이름을 **`secret.xlsx`** 로 바꾸세요 |
| 3 | **[⬇ chromedriver.exe](https://github.com/hihiood/place-launcher/releases/latest/download/chromedriver.exe)** | 크롬 제어 파일 (40MB) |

폴더 안이 이렇게 되면 준비 완료입니다.

```
아무폴더├── PlaceLauncherV10.exe
├── secret.xlsx
└── chromedriver.exe
```

새 버전은 [Releases](https://github.com/hihiood/place-launcher/releases) 에서 확인하세요.

## 사용설명서

처음 쓰신다면 아래 설명서를 먼저 보세요. 화면을 하나씩 짚어가며 설명합니다.

### **[📖 사용설명서 보기](docs/MANUAL.md)**

- 설치와 첫 실행
- 작업 설정 (매장 · 검색어 · 트래픽 버튼)
- 실행 옵션 (화면 모드 · IP 변경 · 진입 방식 · 캡차)
- AntiDetect (API 키 발급 · 포인트 충전)

- 자주 묻는 것

## 실행

1. `PlaceLauncherV10.exe` 를 실행합니다.
2. **"Windows의 PC 보호" 경고가 뜨면** `추가 정보` -> `실행` 을 누르세요.
   코드 서명이 없어서 나오는 안내이며, 실행에는 문제가 없습니다.
3. 처음 실행 시 프로그램 파일을 내려받으므로 잠시 기다려 주세요.

## 요구 사항

- Google Chrome 설치
- 인터넷 연결
